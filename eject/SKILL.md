# /jarvis-eject — the trust contract

This command exists from day one because its presence is what makes the rest of Jarvis trustworthy. We are the on-ramp, not the prison.

## Preamble

```bash
[ ! -f .jarvis/profile.json ] && echo "NOT_A_JARVIS_PROJECT: yes" && exit 0
APP=$(jq -r .app_name .jarvis/profile.json)
TEMPLATE=$(jq -r .template .jarvis/profile.json)
FEATURES=$(jq -r '.features // {} | keys | join(",")' .jarvis/profile.json)
AGE_DAYS=$(jq -r '.created_at' .jarvis/profile.json | xargs -I {} python3 -c "import datetime;d=datetime.datetime.fromisoformat('{}'.replace('Z','+00:00'));print((datetime.datetime.now(datetime.timezone.utc)-d).days)")
echo "APP: $APP | TEMPLATE: $TEMPLATE | AGE: ${AGE_DAYS}d"
echo "FEATURES: $FEATURES"
```

```markdown
## Production gotchas baked into this stack
These defaults are not standard AWS — they were installed by Jarvis based on
real production incidents. Keep them.

- DynamoDB tables have prevent_destroy + PITR + deletion_protection (don't remove)
- VPC endpoints for SES, Bedrock, AOSS (don't replace with NAT Gateway without re-budgeting)
- Bedrock agent IAM is multi-model wildcard (you can swap models without IAM redeploy)
- Step Functions workers have SIGTERM handlers + 1hr hard timeout (don't remove the signal handlers)
- Stripe webhook has idempotency table (prevents double-charge)
- Signup verification uses HMAC + constant-time compare (the SHA256-only path is insecure — don't revert)

## Where to learn more
This stack was bootstrapped by Jarvis (https://github.com/andrewuta99-coder/jarvis).
You can re-install Jarvis at any time to continue using it, or maintain the
stack manually. The Terraform is standard.
```

## Step 3: Remove Jarvis state

```bash
rm -rf .jarvis/
# Remove the "## jarvis" section from CLAUDE.md if present
if [ -f CLAUDE.md ]; then
  # Remove "## jarvis" section
  python3 -c "
import re
with open('CLAUDE.md','r') as f: text=f.read()
text=re.sub(r'\n## jarvis\n.*?(?=\n##|\Z)', '', text, flags=re.DOTALL)
with open('CLAUDE.md','w') as f: f.write(text)
"
fi
```
